เว็บแอปพลิเคชันสำหรับสร้าง **วิดีโอโฆษณาสินค้าสั้น (Short-Form Commercial Video Ad สำหรับ TikTok / Reels / Shorts / Feed)** โดยรับอินพุตเป็น **ภาพถ่ายสินค้า 1–3 มุมมอง** คู่กับ **ชุดตัวอย่าง Prompt โฆษณาสำเร็จรูป 6 หมวดหมู่** แล้วสั่ง **LM Studio (`:1234`)** แต่งคำโปรยโฆษณา 3 ฉาก พร้อมสั่ง **ComfyUI (`:8188`)** สร้างฉากหลังสตูดิโอและประกอบเป็นไฟล์วิดีโอแอนิเมชัน 36 เฟรม (`.webp` และ `.gif`)

## ทำไมจึงออกแบบให้ใช้ภาพสินค้า 1–3 ภาพ? (3-Shot Commercial Formula)

ในการทำวิดีโอโฆษณาสินค้าสั้นที่มีประสิทธิภาพสูงสุดบนโซเชียลมีเดีย โครงสร้างมาตรฐานของวงการโฆษณาจะใช้ **3 มุมมอง (3-Act Visual Arc)** ซึ่งพอดีกับงบหน่วยความจำการ์ดจอ RTX 3050 (6GB VRAM) โดยไม่ต้องเรนเดอร์ซ้ำจนล้น:

1. **ภาพที่ 1 — มุมหลักหน้าตรง (Hero Packshot • ฉากเปิด Hook):** ดึงสายตาผู้ชมในวินาทีแรกด้วยภาพสินค้าที่ชัดเจนที่สุด พร้อมพาดหัวเปิดเรื่อง (*Hook Headline*)
2. **ภาพที่ 2 — มุมเฉียง 45° หรือเจาะดีเทล (Detail / Texture Shot • ฉากกลาง Benefit):** โชว์รายละเอียดวัสดุพื้นผิวของสินค้า พร้อมคำโปรยจุดขายหลัก (*Key Benefit*)
3. **ภาพที่ 3 — ภาพตอนใช้งานหรือแพ็กเกจปิดท้าย (Lifestyle / Closing Packshot • ฉากจบ Offer):** ปิดการขายพร้อมป้ายโปรโมชัน (*Call-to-Action Badge*)

> **ยืดหยุ่นทุกรูปแบบ:** หากคุณมีภาพสินค้าแค่ **1 ภาพ** (หรือกดทดสอบโดยยังไม่ได้อัปโหลดภาพ) ระบบจะทำ Dynamic Camera Zoom, Angle Tilt และจัดแสงให้ครบทั้ง 3 ฉากโดยอัตโนมัติ!

## ชุดตัวอย่าง Prompt โฆษณาสินค้า 6 สไตล์ในตัว (One-Click Prompt Presets)

บนหน้าเว็บมีปุ่มให้คลิกเลือกชุดตัวอย่าง Prompt โฆษณาสำเร็จรูป 6 หมวดหมู่ (คลิกปุ๊บเติมชื่อสินค้า จุดขาย และ Prompt ฉากหลังสตูดิโอให้ทันที และแก้ไขข้อความเองได้อิสระ):
1. ☕ **กาแฟสกัดเย็น & เครื่องดื่มพรีเมียม (`coffee_beverage`)**
2. 🧴 **สกินแคร์ & เซรั่มบำรุงผิว (`luxury_skincare`)**
3. 🎧 **หูฟังไร้สาย & แกดเจ็ตไอที (`tech_gadget`)**
4. 👟 **รองเท้าผ้าใบ & สตรีทแวร์ (`street_sneaker`)**
5. 🥐 **ขนมอบโฮมเมด & อาหารพรีเมียม (`gourmet_food`)**
6. ⌚ **นาฬิกาข้อมือ & แอ็กเซสซอรีหรู (`minimal_watch`)**

## วิธีเปิดใช้งาน Web App

เปิด Terminal / PowerShell ที่โฟลเดอร์หลักของโปรเจกต์ เปิดใช้งาน `.venv` แล้วรันคำสั่ง:

```bash
python 07-product-ad-studio/app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่:
👉 **`http://127.0.0.1:8095`**

*(ไฟล์วิดีโอโฆษณาที่สร้างเสร็จจะถูกบันทึกไว้ใน `07-product-ad-studio/outputs/` ทั้งนามสกุล `.webp` และ `.gif` พร้อมประวัติแคมเปญใน `ad_campaigns_history.csv`)*
