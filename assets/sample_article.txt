การรันโมเดลภาษาและโมเดลสร้างภาพบนคอมพิวเตอร์ส่วนบุคคล (Local AI Stack)

ช่วงไม่กี่ปีมานี้ ระบบ Generative AI บนคลาวด์อย่าง ChatGPT หรือ Midjourney กลายเป็นเครื่องมือที่หลายคนใช้ทำงานทุกวัน แต่สำหรับห้องเรียนและองค์กรที่ต้องทำงานกับเอกสารภายใน การส่งข้อมูลออกไปประมวลผลข้างนอกยังมีข้อจำกัดทั้งเรื่องความเป็นส่วนตัวและค่าใช้จ่าย ทางเลือกที่ใช้งานได้จริงในตอนนี้คือการนำโมเดลภาษาขนาดเล็ก (Small Language Models) และโมเดลสร้างภาพ (Diffusion Models) มารันบนเครื่องคอมพิวเตอร์ในห้องปฏิบัติการโดยตรง ไม่ว่าจะเป็นพีซีที่ใช้การ์ดจอ NVIDIA GeForce RTX 3050 ที่มี VRAM 6GB คู่กับซีพียู Intel Core Ultra 7 265 หรือเครื่อง MacBook ตระกูล Apple Silicon (M1, M2, M3 และ M4) ที่ใช้หน่วยความจำแบบ Unified Memory

สิ่งที่ทำให้คอมพิวเตอร์ทั่วไปรันโมเดลเหล่านี้ได้โดยไม่ค้างคือการบีบอัดโมเดลที่เรียกว่า Quantization เช่น การแปลงโมเดลให้อยู่ในฟอร์แมต GGUF ระดับ 4-bit (Q4_K_M) วิธีนี้ช่วยลดขนาดของโมเดลภาษา 3 พันล้านพารามิเตอร์ (3B) อย่าง Qwen 2.5 หรือ Llama 3.2 ให้ใช้พื้นที่ใน VRAM ประมาณ 2.2 GB เท่านั้น แต่ยังอ่านบทความภาษาไทย แปลภาษา และดึงข้อมูลออกมาเป็นโครงสร้าง JSON ได้แม่นยำ เมื่อนำมาต่อเข้ากับโมเดลสร้างภาพ Stable Diffusion 1.5 (SD 1.5) บนโปรแกรม ComfyUI เราจะเขียนโค้ดรับหัวข้อสั้นๆ แล้วสั่งสร้างเนื้อหาพร้อมภาพประกอบขนาด 512x512 พิกเซลได้เสร็จภายในเวลาไม่กี่วินาที

การนำเครื่องมือทั้งสามตัวมาทำงานร่วมกันประกอบด้วย Jupyter Notebook สำหรับเขียนสคริปต์ภาษา Python ควบคุมลำดับงาน, LM Studio สำหรับจำลองเซิร์ฟเวอร์ LLM ในเครื่องที่รองรับคำสั่งแบบเดียวกับ OpenAI API และ ComfyUI สำหรับรับคำสั่งเรนเดอร์ภาพผ่านระบบ API การต่อระบบเข้าด้วยกันแบบนี้ช่วยแก้ปัญหาหลักของการใช้บริการบนคลาวด์ได้สามเรื่อง คือ ข้อมูลและเอกสารทั้งหมดประมวลผลอยู่ในเครื่องตัวเองร้อยเปอร์เซ็นต์, ไม่เสียค่าเช่ารายเดือนหรือค่า API Token ตามจำนวนคำที่ใช้งาน และสามารถรันงานทั้งหมดแบบออฟไลน์ได้ทันทีแม้ในห้องแล็บที่อินเทอร์เน็ตมีปัญหา
