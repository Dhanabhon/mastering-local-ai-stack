Node-Based Image Generation with ComfyUI

ไฟล์เวิร์กโฟลว์อ้างอิง: 03-comfyui-workflows/sd15_txt2img_api.json

เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:8188 โหลด Default Workflow ของ Stable Diffusion 1.5 แล้วตรวจสอบการเชื่อมสายระหว่างโหนด:

  • Load Checkpoint (Node 4): เลือกไฟล์ v1-5-pruned-emaonly.safetensors (หรือ DreamShaper_8_pruned.safetensors)
  • CLIP Text Encode (Node 6 & 7): กล่องบนใส่ Positive Prompt ภาษาอังกฤษ กล่องล่างใส่ Negative Prompt (เช่น text, watermark, blurry, low quality)
  • Empty Latent Image (Node 5): ตั้งค่า width = 512, height = 512, batch_size = 1
  • KSampler (Node 3): ตั้งค่า steps = 20, cfg = 7.0, sampler_name = euler, scheduler = normal

คลิกปุ่ม ▶ Run (หรือกดคีย์ลัด Ctrl + Enter / ใน UI รุ่นเก่าจะเขียนว่า Queue Prompt) บนหน้าเว็บ ComfyUI สังเกตกรอบสีเขียวที่วิ่งผ่านโหนด Load Checkpoint -> CLIP -> KSampler -> VAE Decode -> Save Image (ใช้เวลาประมาณ 2–3 วินาทีต่อภาพบน RTX 3050 6GB และ Apple Silicon)

ทำไมต้องทำขั้นตอนนี้? ในบทที่ 4 เราต้องการให้โค้ด Python สั่ง ComfyUI วาดรูปอัตโนมัติโดยไม่ต้องสลับหน้าจอมากดปุ่ม ▶ Run เอง แต่โค้ด Python ไม่สามารถอ่านไฟล์กราฟปกติ (Workflow → Export ที่เก็บแค่พิกัดกล่องและสีบนหน้าจอ) ได้ เราจึงต้องส่งออกเป็นไฟล์ API Format ที่เก็บเฉพาะคำสั่งของแต่ละโหนดล้วนๆ

  1. คลิกไอคอนรูปเฟือง ⚙️ Settings (มุมซ้ายล่างหรือขวาบนของหน้าเว็บ ComfyUI)
  2. พิมพ์ค้นหาคำว่า Dev Mode ในช่องค้นหาตั้งค่า แล้วเปิดสวิตช์ Enable Dev mode Options จากนั้นกดปิดหน้าต่าง Settings
  3. คลิกเมนูมุมซ้ายบน Workflow → Export (API) (หรือปุ่ม Save (API Format) ใน UI รุ่นเก่า) ตั้งชื่อไฟล์แล้วกดยืนยัน เบราว์เซอร์จะดาวน์โหลดไฟล์ .json ลงมาในเครื่องของคุณ
  4. หมายเหตุ: ในคลังโปรเจกต์ของเราได้เตรียมไฟล์ที่กด Export (API) แบบเดียวกันนี้ไว้ให้พร้อมใช้งานแล้วที่ 03-comfyui-workflows/sd15_txt2img_api.json (คุณจึงไม่ต้องเสียเวลาย้ายไฟล์จากโฟลเดอร์ Downloads ด้วยตัวเอง)

หลังจากรู้วิธี Export (API) แล้ว ขั้นตอนนี้คือการ "เปิดดูไส้ในของไฟล์ JSON เฉยๆ (ไม่ต้องพิมพ์แก้ในไฟล์ JSON)" เพื่อดูว่ากล่องโหนดทั้ง 7 กล่องบนหน้าเว็บ ComfyUI ถูกแปลงเป็นหมายเลขโหนดอะไรบ้าง เวลาโค้ด Python ใน Module 4 โหลดไฟล์นี้ไปใช้งาน จะได้อ้างอิงชื่อคีย์ได้ถูกต้อง:

  1. สลับกลับมาที่หน้าต่าง JupyterLab ด้านซ้ายมือ ให้ดับเบิลคลิกเข้าโฟลเดอร์ 03-comfyui-workflows/
  2. คลิกขวา ที่ไฟล์ sd15_txt2img_api.json แล้วเลือก Open With → Editor (เพื่อเปิดดูเนื้อหาไฟล์เป็นข้อความโค้ด JSON)
  3. สังเกตโครงสร้างภายในไฟล์ จะเห็นว่าแต่ละกล่องโหนดถูกแทนที่ด้วยหมายเลขคีย์ "3" ถึง "9" โดยจุดสำคัญที่โค้ด Python ใน Lab 4.1–4.4 จะดึงไปแก้ไขค่าในหน่วยความจำโดยอัตโนมัติมี 3 จุด ดังนี้:
ตัวอย่างโค้ด Python ใน Module 4 ที่จะโหลดไฟล์ JSON ไปแก้ค่าให้อัตโนมัติ (ไม่ต้องก๊อปปี้ไปวางในไฟล์ .json) 
# 1) โหนด "6" คือกล่อง Positive Prompt (บรรทัดที่ 52 ในไฟล์ JSON):
#    "6": { "inputs": { "text": "masterpiece, best quality...", "clip": ["4", 1] } }
workflow["6"]["inputs"]["text"] = "คำสั่งวาดภาพภาษาอังกฤษที่ได้จาก LM Studio"

# 2) โหนด "7" คือกล่อง Negative Prompt (บรรทัดที่ 65 ในไฟล์ JSON):
#    "7": { "inputs": { "text": "text, watermark, blurry...", "clip": ["4", 1] } }
workflow["7"]["inputs"]["text"] = "text, watermark, blurry, low quality"

# 3) โหนด "3" คือกล่อง KSampler (บรรทัดที่ 2 ในไฟล์ JSON):
#    "3": { "inputs": { "seed": 156680208700286, "steps": 20, "cfg": 7.0, ... } }
workflow["3"]["inputs"]["seed"] = 42
ทำไมต้องปรับค่า seed ในโหนด "3"? ค่า seed คืออะไรและส่งผลอย่างไร?
  • ค่า seed คืออะไร: เวลา Stable Diffusion วาดรูป โมเดลจะเริ่มจากการสร้าง "ภาพคลื่นสัญญาณรบกวนแบบสุ่ม" (Random Noise เหมือนภาพซ่าๆ บนจอทีวี) แล้วค่อยๆ เกลาให้กลายเป็นภาพที่คมชัด ค่า seed คือ "รหัสตัวเลขตั้งต้น" ที่ใช้กำหนดหน้าตาของคลื่นรบกวนเริ่มต้นนั้น
  • ส่งผลต่อภาพอย่างไร: หากใช้ Prompt เดิม + ตั้งค่าเดิม + เลข seed เดิม โมเดลจะวาดภาพออกมา หน้าตาเหมือนเดิมเป๊ะ 100% ทุกพิกเซล แต่ถ้าเปลี่ยนเลข seed เป็นค่าใหม่ แม้จะใช้ Prompt เดียวกัน ก็จะได้ภาพที่มีมุมกล้อง ท่าทาง หรือการจัดวางองค์ประกอบแบบใหม่
  • ทำไมสั่งผ่าน Python API ต้องกำหนดค่า seed เอง: เวลาเรากดปุ่ม ▶ Run บนหน้าเว็บ ComfyUI หน้าเว็บจะสุ่มเลข seed ใหม่ให้ทุกครั้งอัตโนมัติ แต่เวลาส่งไฟล์ JSON ผ่านโค้ด Python เข้า API (POST /prompt) ComfyUI จะไม่สุ่มเลข seed ให้เอง และหากส่งเลข seed เดิมซ้ำไปพร้อม Prompt เดิม ระบบ Cache ของ ComfyUI จะข้ามการวาดใหม่แล้วส่งรูปเดิมกลับมาทันที เราจึงต้องใช้ Python สุ่มเลขใหม่ (random.randint(...)) เมื่ออยากได้ภาพใหม่ หรือล็อกเลขคงที่ (เช่น 42) เมื่ออยากทดสอบเทียบ Prompt

⚠️ ข้อควรระวัง: ในขั้นตอนนี้เราแค่เปิดไฟล์ sd15_txt2img_api.json ขึ้นมาดูตำแหน่งโหนด "6", "7" และ "3" เฉยๆ ห้ามก๊อปปี้โค้ด Python ด้านบนไปวางทับในไฟล์ .json เด็ดขาด (เพราะจะทำให้โครงสร้าง JSON พัง) เมื่อดูตำแหน่งโหนดเข้าใจแล้ว ให้ปิดไฟล์ JSON ติ๊กถูกที่ข้อนี้ แล้วไปต่อที่ Lab 4.1 (เปิดไฟล์ 04-capstone-pipeline/04_end_to_end_ai_pipeline.ipynb) ได้เลย!

💡 โจทย์เสริมท้าย Module 3 (สำหรับผู้ที่ทำเสร็จเร็ว): ทดลองปรับ Aspect Ratio แนวนอน/แนวตั้ง และค่า CFG Scale

โจทย์: ในหน้าเว็บ ComfyUI ลองล็อกค่า seed ใน KSampler ให้เป็นค่าคงที่ (เปลี่ยน control_after_generate เป็น fixed) แล้วทดสอบปรับค่าต่อไปนี้:

import re

def generate_storyboard(story_theme: str, num_scenes: int = 3):
    models = llm_client.models.list()
    model_id = models.data[0].id if models.data else "local-model"

    sys_prompt = f"""You are a storyboard director.
Break the user's Thai topic into {num_scenes} sequential scenes.
Return ONLY a valid JSON array with this exact structure:
[
  {{
    "scene_no": 1,
    "thai_narration": "คำบรรยายฉากภาษาไทยสั้นๆ 1 ประโยค",
    "sd_prompt": "masterpiece, best quality, detailed English Stable Diffusion 1.5 prompt for this scene"
  }}
]"""

    res = llm_client.chat.completions.create(
        model=model_id,
        messages=[
            {"role": "system", "content": sys_prompt},
            {"role": "user", "content": story_theme}
        ],
        temperature=0.4,
        max_tokens=700
    )
    raw = re.sub(r"```(?:json)?", "", res.choices[0].message.content).strip()
    match = re.search(r"\[.*\]", raw, flags=re.DOTALL)
    scenes = json.loads(match.group(0) if match else raw)

    for sc in scenes:
        display(Markdown(f"---\n### ฉากที่ {sc['scene_no']}: {sc['thai_narration']}"))
        display(Markdown(f"`Prompt:` *{sc['sd_prompt']}*"))

        wf = json.loads(WORKFLOW_JSON_PATH.read_text(encoding="utf-8"))
        wf["6"]["inputs"]["text"] = sc["sd_prompt"]
        wf["3"]["inputs"]["seed"] = random.randint(1, 999_999_999_999_999)

        pid = queue_prompt(wf)["prompt_id"]
        img = wait_and_fetch_image(pid)
        display(img)

Style Preset & Dynamic Negative Prompt Controller

โจทย์: ปรับปรุงไปป์ไลน์ให้ผู้เรียนเลือก style_preset ได้ (เช่น "Cyberpunk Neon", "Watercolor Illustration", "3D Isometric Render") โดยให้ LM Studio สร้างทั้ง positive_prompt และ negative_prompt ที่เหมาะสมกับสไตล์นั้น แล้วนำค่าไปใส่ทั้งใน Node "6" (Positive) และ Node "7" (Negative) พร้อมกัน

คลิกเพื่อดูโค้ดต้นแบบ / เฉลย Challenge B
Python: ฟังก์ชันควบคุมทั้ง Positive (Node 6) และ Negative Prompt (Node 7) 
STYLE_PRESETS = {
    "cyberpunk": "cyberpunk neon style, rain-slicked streets, holographic glow, cinematic lighting, 8k",
    "watercolor": "soft watercolor painting on textured paper, Studio Ghibli inspired, pastel tones, hand-drawn",
    "isometric": "3D isometric miniature diorama, cute stylized 3d render, Blender Cycles, soft studio lighting"
}

def run_styled_pipeline(user_topic: str, style_key: str = "isometric"):
    style_tags = STYLE_PRESETS.get(style_key, STYLE_PRESETS["isometric"])
    base_prompt = generate_sd_prompt(user_topic)
    final_positive = f"{base_prompt}, {style_tags}"
    final_negative = "text, watermark, blurry, low quality, deformed, ugly, bad anatomy"

    wf = json.loads(WORKFLOW_JSON_PATH.read_text(encoding="utf-8"))
    wf["6"]["inputs"]["text"] = final_positive
    wf["7"]["inputs"]["text"] = final_negative
    wf["3"]["inputs"]["seed"] = random.randint(1, 999_999_999_999_999)

    display(Markdown(f"**Style:** `{style_key}` | **Final Prompt:** `{final_positive}`"))
    pid = queue_prompt(wf)["prompt_id"]
    img = wait_and_fetch_image(pid)
    display(img)
    return img

# ทดลองเปลี่ยน style_key เป็น "cyberpunk", "watercolor", หรือ "isometric"
run_styled_pipeline("ร้านกาแฟเล็กๆ ในกรุงเทพฯ ที่มีหุ่นยนต์บาริสต้าชงกาแฟ", style_key="isometric")

import matplotlib.pyplot as plt

topic = "หอสมุดแห่งอนาคตกลางสวนธรรมชาติในมหาวิทยาลัย"
