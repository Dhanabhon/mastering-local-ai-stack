2. ตั้งค่าเชื่อม LM Studio (:1234) เข้ากับ VS Code Extension (Continue / Cline)

ตัวสร้างไฟล์ตั้งค่าอัตโนมัติสำหรับส่วนเสริม Continue

ใน VS Code ให้ติดตั้งส่วนเสริมชื่อ Continue จากนั้นคลิกไอคอนรูปเฟือง ⚙️ มุมขวาบนของแถบ Continue แล้วเลือกขนาดโมเดลที่คุณโหลดไว้ด้านล่างเพื่อก๊อปปี้โค้ดตั้งค่าไปวางทับได้เลย:

1. เลือกรุ่นโมเดลที่เปิดใน LM Studio (:1234)
2. เลือกรูปแบบไฟล์ตั้งค่าของ Continue
💡 ทิปการตั้งค่าใน LM Studio: ตอนโหลดโมเดลในแถบ Developer แนะนำให้ตั้งค่า Context Length = 4096 หรือ 8192 เพื่อให้ Qwen2.5-Coder อ่านไฟล์โค้ดขนาดยาวได้ครบทั้งไฟล์
~/.continue/config.yaml (พร้อมก๊อปปี้ไปวางใน VS Code)

ทางเลือกเสริม: หากใช้ส่วนเสริม Cline หรือ Roo Code (สาย Agent สร้างไฟล์อัตโนมัติ)

  1. ติดตั้งส่วนเสริม Cline ใน VS Code แล้วคลิกไอคอนรูปเฟือง ⚙️ Settings
  2. ช่อง API Provider เลือกเป็น LM Studio
  3. ช่อง Base URL ใส่ http://localhost:1234 แล้วคลิกเลือกโมเดล qwen2.5-coder-... จากรายการได้เลย

4. ตารางสรุปคีย์ลัดประจำตัวนักพัฒนา (VS Code + Continue Cheat Sheet)

คำสั่งใช้งาน Windows / Linux macOS เทคนิคการเขียน Prompt ให้ Qwen2.5-Coder ตอบแม่นยำที่สุด
ยอมรับโค้ดที่เติมให้อัตโนมัติ Tab Tab เขียนชื่อฟังก์ชันสื่อความหมายชัดเจน + ใส่ Type Hints (เช่น def fetch_status(url: str) -> dict:) และพิมพ์ Docstring สั้นๆ นำร่อง 1 บรรทัด
สั่งแก้โค้ดเฉพาะจุดที่คลุมดำ (Inline Edit) Ctrl + I Cmd + I ลากคลุมเฉพาะฟังก์ชันที่ต้องการแก้ แล้วพิมพ์คำสั่งสั้นๆ เช่น "เพิ่มการดักจับ Error ด้วย try/except และคืนค่าเริ่มต้นเป็น dict ว่าง"
ส่งโค้ดที่คลุมดำเข้าห้องแชต Ctrl + L Cmd + L ใช้ถามคำถามเชิงลึกหรือหาบั๊ก เช่น "ทำไมโค้ดส่วนนี้ถึงเกิด JSONDecodeError เวลา LLM ตอบกลับ และควรแก้อย่างไร"
